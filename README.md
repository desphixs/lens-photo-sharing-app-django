# Build Lens: A Photo Sharing Portfolio

### Project Description

You are going to build Lens, a sleek photo sharing portfolio. You will start by diving into the settings to configure exactly where and how images should be stored on your server. Then, you will build database models that can actually hold raw image files alongside their titles and albums. After that, you will write custom HTML forms capable of transporting heavy files over the internet, and build the Python logic to save them safely. Finally, you will design a beautiful, responsive grid gallery to display all the uploaded photography. You will write everything using raw Django code and function based views so you understand the exact flow of file handling.
